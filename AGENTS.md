# Entrada de la entrega portátil

Lee `INICIO Y CONFIGURACION DE FRAMEWORK.md` y `INICIO_PARA_CODEX.md`. Para iniciar el asistente usa Python 3.11+ con `tools/asistente.py`. Si falta Python utiliza el lanzador nativo de este sistema.

No instales ni descargues dependencias/modelos sin autorización explícita para el plan mostrado. No modifiques el framework de un proyecto externo ni descubras la ruta Mac histórica para escribir allí. Trabaja solo en esta entrega. La bitácora aplicable a una nueva edición está en `proyecto/BITACORA_CURSO_EDICION.md`.

Una preparación de lote no es un video editado ni una aprobación. Después de abrir `proyecto/`, sigue sus AGENTS.md y las reglas del framework; todas las referencias de código necesitan nuevos medios/timing. No ejecutes audio de modelos que no pase el doctor/calibración requerido. No afirmes escucha humana ni equivalencia Windows/Mac sin evidencia.
