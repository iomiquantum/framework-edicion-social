# Current-practice evidence baseline

Last evidence review: 2026-09-27.

Use these sources as directional evidence, not universal guarantees. Re-check them when the request is time-sensitive.

## Attention and opening value

- [YouTube: understand content performance for recommendations](https://support.google.com/youtube/answer/16559650?hl=en) says initial seconds are where viewers decide whether to continue and recommends delivering the promised value quickly.
- [YouTube Shorts deep dive](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/) emphasizes first-second attention and concise miniature stories with a resolution.
- [TikTok creative best practices](https://ads.tiktok.com/resources/help/article/creative-best-practices?lang=en) recommends vertical framing, people, safe zones, and an early proposition/hook.

Translation: make the first visual state state the tension or value; do not spend the opening on a label, logo, or generic context. Verify that the first second already contains a meaningful image and message.

## Vertical format and safe zones

- [Meta Reels creative guidance](https://www.facebook.com/business/ads/facebook-instagram-reels-ads) supports 9:16, audio, and key messages inside safe zones.
- TikTok guidance likewise calls for keeping important information within its UI safe zone.

Translation: an edit title-safe box is only a baseline. Check the actual destination UI separately. Protect faces and key text from both authored graphics and platform chrome.

## Legibility and captions

- [W3C WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) requires 4.5:1 for normal text and 3:1 for large text.
- [W3C accessible audio and video](https://www.w3.org/WAI/media/av/) recommends synchronized captions and foreground audio that remains distinguishable.

Translation: aim for at least 4.5:1 when practical, including small metadata. Keep captions complete and synchronized, but visually separate from large editorial copy.

## Evidence boundaries

- Platform guidance is usually written for creators or advertisers; it does not prove the same result for every educational video.
- “Hook in one second,” “value in three seconds,” and “state change every few seconds” are production hypotheses to test, not algorithmic laws.
- A layout check, screenshot, or contrast pass does not prove retention.
- Only publication analytics and controlled comparisons can support performance claims.
