# STYLE 001 — Tech Editorial Gold

Primer estilo experimental del framework. Está diseñado para presentadores que explican tecnología, IA, procesos o analogías con ritmo ágil.

## Personalidad

- Editorial tecnológica.
- Energética pero clara.
- Alto contraste.
- Acento dorado consistente.
- Tarjetas oscuras con ilustraciones o iconos limpios.

## Uso recomendado

- Talking head vertical.
- Explicaciones de herramientas o procesos.
- Conceptos abstractos que necesitan metáforas visuales.
- Videos donde los recursos aparecen como PIP o collage sin sustituir permanentemente al presentador.

## Evitar

- Demasiados overlays simultáneos.
- Giros continuos que distraigan de la voz.
- Gráficas sin datos.
- Logos generados o nombres de marca no confirmados.
- Cubrir ojos o boca.
