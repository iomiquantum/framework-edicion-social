# STYLE 003 — Immersive Wellness

Preset para respiración, introspección, bienestar y experiencias sensoriales. Mantiene al presentador como ancla humana y usa imágenes conceptuales a pantalla completa para traducir aire, ondas, profundidad y espacio interior.

- Ritmo: `directo → gesto → inmersión lenta → explicación → liberación → CTA`.
- Zoom: 7–9 %, máximo absoluto 10 %, siempre motivado por una frase o gesto.
- Transiciones: una familia coherente de ripple, iris y washes orgánicos.
- Color: navy como base; teal, cyan, lilac, coral y arena cambian según función.
- Audio: cama ambiental sin voz, carve dinámico bajo voz y SFX cortos con intención.
- Restricciones: no promesas médicas, no logos inventados, no glitch o shake, no cubrir ojos o boca con overlays persistentes.
