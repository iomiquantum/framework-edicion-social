# Iconos reutilizables

Biblioteca vectorial code-native. Los SVG mantienen fondo transparente, `viewBox` 64×64 y trazos legibles en móvil. Pueden recolorearse por estilo o copiarse al editable de un proyecto; el significado semántico no debe cambiar.

Colección inicial wellness:

- `eye.svg`: cerrar los ojos o atención interior.
- `headphones.svg`: escucha con audífonos.
- `breath.svg`: inhalación, exhalación o respiración guiada.
- `waves.svg`: sonido, resonancia u ondas envolventes.

No usar un icono como evidencia científica ni como sustituto de un logo oficial. Registrar cada copia en el manifiesto del proyecto.
