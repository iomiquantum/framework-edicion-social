# Guía de SFX para atención en video corto

## Conclusión práctica

El sonido sí puede dirigir la atención, pero funciona mejor como **punto de sincronía**: un evento auditivo breve que coincide con una entrada, cambio o gesto visual significativo. No se recomienda llenar cada palabra o movimiento con un efecto.

La evidencia experimental indica que los sonidos relacionados y sincronizados con un evento visual orientan la mirada hacia ese evento. También muestra que la congruencia semántica audiovisual beneficia la memoria, mientras que el sonido irrelevante o una densidad sensorial excesiva puede competir con el mensaje.

Fuentes principales:

- [Inducing visual attention through audiovisual stimuli: Can synchronous sound be a salient event?](https://pmc.ncbi.nlm.nih.gov/articles/PMC10798022/)
- [Semantic congruency but not temporal synchrony enhances long-term memory performance for audio-visual scenes](https://pubmed.ncbi.nlm.nih.gov/26620810/)
- [Low Message Sensation Health Promotion Videos Are Better Remembered](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0113256)
- [Watching subtitled videos with the sound off affects comprehension, cognitive load, immersion and enjoyment](https://pmc.ncbi.nlm.nih.gov/articles/PMC11458047/)

## Regla editorial inicial

Para videos de 15–25 segundos:

1. Usar una firma de hook de una o dos capas durante los primeros 600 ms: golpe suave de entrada y acento corto sobre la palabra o cambio visual principal.
2. Añadir SFX únicamente en cambios semánticos, transiciones importantes o CTA. El efecto debe explicar o reforzar lo que ocurre en pantalla.
3. Evitar efectos continuos, sonidos por cada palabra y novedades auditivas sin relación con el guion.
4. Mantener la voz como capa dominante. Como default interno de mezcla —no como hallazgo científico— los acentos deben sentirse claramente por debajo de la voz y el máster debe respetar el límite de true peak del perfil.
5. Conservar captions y comprensión visual completa para reproducción sin sonido.
6. Tratar número de SFX, timbre y firma inicial como variables de prueba. Comparar retención inicial, finalización y señales de fatiga antes de promover un default.

## Gate de QA

- Cada SFX tiene un evento visual y una intención semántica identificables.
- Inicio, cambio de escena y cierre no usan automáticamente el mismo sonido.
- Los dos primeros segundos contienen como máximo una firma compacta, no una secuencia invasiva.
- La voz sigue siendo inteligible en altavoz de teléfono y auriculares.
- El MP4 final se mide por loudness y true peak y se escucha completo.
